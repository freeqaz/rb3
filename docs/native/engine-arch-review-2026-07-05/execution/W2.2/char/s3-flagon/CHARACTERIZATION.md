## Scope note — head/hands rebake vs lower-body path

`RebindHeadHandsAtRest` (W2.2's scope) targets **head/hair/hands/face** only. Foot/
shoe meshes (`saddleshoe*`, `wovensteppers*`, `feet_naked*`) go through the
torso/lower-body path (`RebindOutfitBonesToOwnSkeleton`, torso-only) or stay
un-rebound. Any HARD drop on a *foot/shoe* mesh is a **sibling lower-body residual**,
not the head/hands rebake — S2 should treat it as an optional coverage extension,
not evidence the head/hands rebake is broken. The head/hands appendages themselves
show NO fling / NO tripwire / NO drop under the rebake — only the marginal grazes.
