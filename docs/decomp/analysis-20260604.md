## Code Change: `Gem::operator=` wrong return value

**File**: `src/band3/bandtrack/Gem.cpp:55`
**Pattern**: `return_this_op_assign` from `docs/decomp/patterns/fixable-declarations.md`

The function `Gem::operator=` (NonMatching) returned the argument `(Gem &)g` instead of
`*this`. This is the documented pattern: without `return *this;`, MWCC does not pin `this`
to r3, cascading r3↔r4 register swaps throughout the function.

```cpp
// Before (wrong): returns argument, not *this
return (Gem &)g;

// After (correct):
return *this;
```

**Impact**: Confirmed fixable per `fixable-declarations.md` (same as DateTime.cpp, Time.cpp
from 2026-06-02 session, and FileMerger::Merger which went 64.6% → 100%). Expected to
improve match% when toolchain is available.
