From [fixable-operators.md](patterns/fixable-operators.md):

|---|---|---|

### 2c. `operator=` Returning Argument Instead of `*this` (1 confirmed hit)

From [return-this-op-assign.md](patterns/return-this-op-assign.md):
> The pattern fires when `operator=` returns `*this`-equivalent via correct ABI, forcing `this` to live in `r3` throughout.

**`band3/bandtrack/Gem.cpp:55`** — `Gem::operator=` returns `(Gem &)g` instead of `return *this`:

```cpp
// Current (line 32–55):
Gem &Gem::operator=(const Gem &g) {
    (GameGem &)mGameGem = g.mGameGem;
    mSlots = g.mSlots;
    // ... 15 more member assignments ...
    return (Gem &)g;   // ← wrong: returns argument, not *this
}
```

**Action**: Change `return (Gem &)g;` → `return *this;`. The cast-to-argument pattern likely aliases `g == this` (self-assign guard), but the register allocator difference may affect match%.
