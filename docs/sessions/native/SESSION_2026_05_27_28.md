## Decisive bug-finds (in order of impact)

1. **`_PoolAlloc(classSize, reqSize)` LP64 MI under-allocation** (K-heap, K1 follow-on) — was passing `classSize` instead of `max(classSize, reqSize)`. Every multi-inheritance derived class (VorbisReader: StreamReader + CriticalSection, etc.) was silently under-allocated under HX_NATIVE. Matched-fork had a `MILO_ASSERT(reqSize==classSize)` that caught it; HX_NATIVE path silently dropped it.

2. **`LocaleChunkSort::FastSort<3>` LP64 pointer-truncation** (V5c) — compared 4 bytes (int) instead of 8-byte pointers AND stepped 8 bytes assuming `DataNode` was 8 bytes (actually 16 on LP64). ~50% of locale lookups silently missed, leaking raw symbol names everywhere.

3. **tomcrypt `aes.c` / `crypt.c` / `ctr.c` were never compiled** (K5) — `file(GLOB ENGINE_SYNTH *.cpp)` doesn't match `.c` files; weak no-op stubs in `rndobj_synth_link_stubs.s` won. Decryption "succeeded" by leaving plaintext as leftover heap garbage. Three lines in `CMakeLists.txt`.

4. **`NetSession::StartGame` weak no-op stub** (V3) — real impl lives in un-globbed `network/net/NetSession.cpp`. SyncStartGameMsg never propagated → `sync_audio_net_panel.mState` stuck at 0 → `kTransitionTo` stalled → `Game::Go()` never fired. Strong native impl in `rb3_netsession_native.cpp` unblocked the entire gameplay state machine.

5. **`WaitingUserGate` weak no-op ctor** (V5a) — `_NATIVE_FORK_EXCLUDE` had it; weak ctor doesn't set vtable; `new` returned object with garbage vtable; deleting-dtor at shutdown SIGSEGV. Native shim emits real vtable.

6. **`StreamReceiverNative::SendDoneImpl` back-pressure deadlock** (K6) — back-pressure during pre-fill prevented `kInit→kReady` transition because the audio thread isn't registered with AudioDevice yet. Gate back-pressure to `kPlaying && mRegistered`.

7. **Render pipeline alpha-write bug** (V3-render extension) — `key.alphaWrite=true` made fragments with `material.color.a=0` overwrite framebuffer alpha to 0. Renderers display alpha=0 as transparent → looks identical to red flood when red-clear bleeds through compositing. `key.alphaWrite=false`.

8. **`RndTex::SyncBitmap` no-op** (V1 render) — entire game rendered flat-colored. Implemented full bitmap upload path with DXT1/3/5 CPU decompress, fingerprint cache, lazy `MakeMaterialBindGroup` binding.

9. **`midi/*.cpp` never compiled** (X7a) — `MidiReader::ReadAllTracks` was a weak no-op stub; chart parsing did nothing visible. Added `ENGINE_MIDI` source glob; 3 clang-LP64 fixes (STLport iter, POSIX `index` collision, switch jump-over-init).

10. **`BandRnd::DrawMesh` hardcoded blend/zmode** (V4) — every material rendered with `WgpuBlend::Src`/`WgpuZMode::Normal` regardless of its actual mode. Text on textured backgrounds was invisible. Cast from material's `mBlend`/`mZMode` (enum values match 1:1).
